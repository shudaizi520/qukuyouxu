# 歌单封面与外观主题设计

## 目标与范围

用户希望歌单像 Plex/Playlist 一样能展示已有音乐封面，同时保持界面干净；希望在页面右上角用衣服图标切换几种克制的背景主题，不能牺牲文字可读性。这里的“封面”指歌单列表缩略图和打开歌单后的标题区；歌曲表格仍以文字为主，避免每行新增图片造成拥挤。外观选择作用于应用全部页面，包括歌单工作台内嵌的设置、导入和曲库页面。

成功标准：有 Plex 封面的歌单能显示封面或前几首歌曲的封面拼图；缺图时显示一致的占位图，不出现破图、纯绿色方块或闪烁；切换主题后所有页面的文字、按钮、表单和提示仍清晰可读，字体、字号及信息布局不变。

## 方案选择

封面使用现有 Plex 曲目缩略图与服务端受控图片代理，不直接把 Plex Token 或任意 Plex URL 暴露到浏览器。优先采用歌单自身可用的图片；若 Plex 没有歌单图片，取该歌单最多四首有封面的歌曲，组成方形拼图。歌单图片候选按当前“用户 + 曲库”身份读取；切换账户时清除旧候选，禁止跨用户复用。图片缺失、Plex 暂时离线或读取失败，只影响封面占位，不阻断歌单和歌曲列表。列表图片懒加载并限制并发；短期缓存候选，歌单内容更新后失效。

不采用浏览器直接请求 Plex 图片的方案，因为会受认证、反代及跨域影响；也不把整张曲库的图片预抓取到本地，因为增加安装体积、首次加载和维护成本。

## 界面

- 左侧自建歌单显示小方形缩略图；智能歌单与曲库整理的卡片显示较大的方形封面。名称和首数仍是主要信息，封面只辅助辨认。
- 打开歌单后在标题旁放一个适中的封面，不改变播放、删除等操作的位置。窄屏时封面缩小，标题和按钮可换行但不溢出。
- 无图歌单使用与当前主题协调的双色渐变及简洁音符占位；加载失败自动回退，不显示错误文字。
- 右上角衣服图标打开小型主题菜单，提供“清爽浅色”（现有风格）、“暖色纸感”和“深色夜间”。菜单显示名称及色块、当前选中状态；支持键盘、Escape 和点击外部关闭。移动端仍可见、可操作。
- 主题只改变背景、表面、边框、强调色和对应文字颜色，不改变字体家族、字号、字重、行高或页面结构；避免装饰性花纹和高饱和背景。偏好保存在当前浏览器，本地切换立即生效；嵌入页与独立页保持一致。

## 数据与安全边界

封面读取沿用已登录的会话和当前 profile 的 Plex 客户端。新增的封面元数据/图片访问必须校验歌单归属及曲库身份，图片路径只允许 Plex 已知的图片路径形式，不能成为任意 URL 代理。失败返回可回退状态；不修改 Plex 歌单、不上传封面、不写入音乐文件。

主题偏好只在浏览器本地保存，不放进 Plex 或管理员全局设置；未保存、值无效或本地存储不可用时使用“清爽浅色”。登录页及首次创建管理员账户页也按相同主题显示，不能出现初始白屏或明显闪色。

## 验证

增加后端测试覆盖封面候选、用户/曲库隔离、非法路径与无图/离线回退；增加前端交互测试覆盖主题持久化、跨页同步、菜单键盘操作和图片回退。执行现有测试，并在桌面和窄屏检查三种主题下的歌单、导入、设置、每日推荐与登录页面的对比度、溢出和可点击性。
