# 固定歌单工作台与可靠播放器设计

## 目标

把“我的歌单”改成真正的音乐应用工作台，而不是随页面滚动的普通网页；同时解决 FLAC 歌曲第一次点击失败、点击“重试”后才播放的问题。

## 已确认的问题

- 浏览器当前滚动的是整个页面，因此顶部导航、歌单标题和底部播放器会离开视野。
- 左侧歌单与“创建与整理”采用两套高亮状态，会同时出现两个选中项。
- 页面上的“搜索歌曲”只筛选当前歌单，不符合“搜索整个当前 Plex 曲库”的需求。
- 播放器默认隐藏、失败提示悬浮在内容上方，控件在不同宽度下错位。
- `preload="metadata"` 在设置音频地址时先触发一次读取，紧接着的 `play()` 可能再次请求 Plex 转码；实际探测显示同一 FLAC 紧邻的第一次转码请求返回 MP3，第二次返回 HTTP 400，符合“第一次点击失败、稍后重试成功”的现象。
- 外部歌单等嵌入工具通过动态 iframe 高度推动整个页面，破坏固定工作台。

## 页面结构

桌面版使用一个占满视口的固定应用框架：

1. 顶部栏固定，包含品牌、全库搜索、运行状态、设置和退出。运行状态与设置在同一个工作台内部切换，不触发整页导航。
2. 左侧栏固定在顶部栏和播放器之间。账户选择、歌单列表与工具入口都在左栏；只有歌单列表自身可以滚动。
3. 主区域固定在顶部栏和播放器之间。歌单标题、操作按钮及表头固定，只有歌曲列表滚动。
4. 底部播放器始终显示，未选歌时展示“暂未播放”的禁用状态。
5. `body` 不滚动，页面任何状态都不能在歌曲列表上方或播放器下方露出旧内容。

小屏幕不强行塞入桌面三栏。宽度不足时左栏变为可开关抽屉，顶部和播放器仍固定，内容区独立滚动。

## 导航状态

只维护一个当前工作区状态：`playlist`、`search`、`tool` 或 `system`。

- 进入歌单时，仅对应歌单高亮。
- 进入“新建智能歌单 / 导入外部歌单 / 曲库整理”时，仅对应工具高亮，所有歌单取消高亮。
- 进入“运行状态 / 设置”时，仅顶部对应入口高亮，左侧歌单与工具都不高亮；内容在工作台内打开，不销毁播放器。
- 进入全库搜索结果时，侧栏不保留虚假的当前项高亮。
- 切换账户时停止旧账户播放，清空旧搜索结果和旧高亮，再加载新账户默认歌单。
- 加载中的临时选择不能与当前页面产生第二个高亮。

## 全库搜索

顶部搜索框搜索当前账户所选 Plex 音乐资料库的完整目录，匹配歌名、歌手和专辑，不再作为当前歌单过滤器。

- 提交搜索后，结果在主区域显示，不使用弹窗遮挡播放器。
- 搜索结果可以直接播放，并建立独立播放队列。
- 每个结果可以选择一个已创建歌单加入。
- 清空搜索或点击返回时恢复原歌单及其滚动位置。
- 当前歌单内不再放一个容易误解的大搜索框；未来若需要筛选，只能作为明确标注“筛选本歌单”的次级操作。

## 播放器与播放可靠性

播放器高度固定为紧凑的一行：左侧封面、歌名与歌手；中间上一首、播放/暂停、下一首和进度；右侧队列位置、静音与音量。

- `<audio>` 使用 `preload="none"`，设置曲目后只由明确的播放动作启动网络请求。
- 每次播放分配递增请求代号；过期曲目产生的 `play()` 拒绝或 `error` 事件不得污染新曲目。
- 首次非用户权限类失败时，播放器等待短暂清理窗口后自动重新加载同一地址并重试一次。
- `NotAllowedError`（浏览器要求用户手势）不自动重试，而是在播放器内部给出明确提示。
- 两次均失败后，错误信息在底部播放器内部显示，并提供“重试”和“下一首”；不使用悬浮通知遮挡歌曲。
- 切换歌单、搜索、导入、曲库整理、运行状态和设置不会停止当前播放，也不会重新创建播放器；切换账户、退出登录、刷新网页或用户主动暂停才停止并复位播放器。
- 后端为曲库搜索结果提供与歌单曲目同样受账户和目录约束的音频、封面路由。
- Plex 曲目存在多个可访问媒体文件时，选择已标记选中的媒体，否则按 Plex 顺序选第一个安全媒体，不能因为数量大于一直接拒绝。

## 嵌入工具

外部歌单、智能歌单和曲库整理仍复用现有业务页面，但 iframe 必须填满主区域的可滚动容器：

- 不再把 iframe 高度同步成几千像素来推动父页面。
- 工具栏固定，iframe 内部滚动。
- 返回歌单后恢复原歌单，不产生两个高亮。
- 顶部“运行状态 / 设置”也作为受控工作区载入，不能进行会销毁 `<audio>` 的整页跳转。
- 后续主题和壁纸只改变变量、颜色与背景，不改变上述布局尺寸和滚动责任。

## 验收标准

- 1440×900 与 1920×1080 下，页面滚动时顶部、左栏、歌单头和播放器不移动。
- DOM 中任意时刻最多只有一个侧栏按钮带 `active`。
- 未播放、播放中、暂停和错误状态下，播放器都占据同一个固定区域。
- 从第一首 FLAC 开始播放不会先向用户报错；必要时在内部自动重试一次。
- 连续切换歌曲不会让旧请求的错误覆盖当前歌曲。
- 从正在播放的歌单切换到运行状态、设置或任一创建工具，声音不中断且进度连续。
- 全库搜索结果包含不在当前歌单内的匹配曲目，并可播放、加入目标歌单。
- 最后一首歌曲可完整滚动到播放器上方，不被遮住。
- 所有现有测试继续通过，并增加固定框架、导航唯一状态、全库播放路由和首次自动恢复的回归测试。
